Generate PPTTemplate presentasi + data shapefile → slide siap edit & simpan

1. Template presentasi
Klik atau seret file template (.pdf atau .pptx)
2. Data DJPA (ZIP shapefile)
Wajib. ZIP berisi .shp, .dbf, .prj (mis. DJPA.zip)
3. Titik Survei (TS.zip)
Opsional. ZIP shapefile titik survei lapangan
4. Hak Atas Tanah (HAT.zip)
Opsional. ZIP shapefile HAT (kolom TIPEHAK, LUAS_HA)
Unggah template dan DJPA (wajib); TS dan HAT opsional, lalu klik Generate.
Klik teks atau sel tabel untuk mengedit. Klik elemen untuk memilih (Delete = hapus), lalu seret ✥ untuk memindah atau kotak di pojok kanan-bawah untuk mengubah ukuran. Gambar/grafik juga bisa diseret langsung.
